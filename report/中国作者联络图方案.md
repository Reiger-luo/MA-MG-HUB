# 中国作者联络图方案

> 模块定位：中国 MG 证据地图 / 作者联络图。本文仅定义方案，不直接实现前端与管线代码。  
> 当前站点：MA-MG-HUB v5，静态 GitHub Pages + Python 数据管线 + `window.MG_*` 前端数据对象。

---

## 1. 已确认决策

| 用户决策 | 方案落实 |
|---|---|
| 只做中国作者联络图 | graph 数据只纳入中国相关文献与中国医院节点；不做全球作者网络 |
| 热力图可以全作者制作 | geographic heatmap 统计所有作者/所有 affiliation 中的中国医院、省市 |
| 联络图用全部第一作者 + 全部通讯作者 | collaboration graph 的作者与机构边只从 `first_authors` + `corresponding_authors` / `author_affiliations.is_first/is_corresponding` 生成 |
| 合作边界 ≥1 | 任意两家归一化医院在同一篇纳入文献中共同出现即生成边；权重为共同文献数 |
| 规则落到医院层级 | 所有 affiliation 先归一到 hospital-level canonical institution，再聚合节点/边 |
| 知识图谱式交互 | 点击医院节点显示合作医院、作者、主题和文献；点击医院-医院边显示合作文献清单 |

## 3. 模块边界

### 3.1 纳入范围

1. 疾病范围：MG / myasthenia gravis corpus 内文献。
2. 地理范围：中国相关研究：mainland China + Hong Kong + Macau + Taiwan 可标记，但默认“中国医院网络”以大陆医院为主，可筛选港澳台。
3. 热力图：纳入中国相关文献中的全作者 affiliation，统计医院/城市/省份出现频次。
4. 联络图：仅纳入每篇文献的全部第一作者与全部通讯作者对应医院。
5. 合作边：同一篇文献内 ≥2 家归一化医院共同出现即建边，阈值 ≥1。

### 3.2 排除范围

| 排除项 | 原因 |
|---|---|
| 全球作者网络 | 用户明确只做中国作者联络图 |
| 会议摘要单独来源 | 模块2以 PubMed literature / 中国证据底座为主；会议内容留在会议资讯页 |
| 非医院层级泛机构边 | 例如 “Department of Neurology”“China”“School of Medicine” 不作为最终节点 |
| 作者个人关系图首版 | 首版聚焦 hospital-level institution graph；作者只作为节点详情属性 |
| 手工内部联系/拜访数据 | 公开站不能提交内部敏感数据 |

## 4. 数据解析规则

### 4.1 文献输入优先级

```text
本地构建时：data/literature-full.json（若存在）
  → 生成公开 data/china-author-network.js
  → 前端只读取公开聚合结果

GitHub Actions/轻量兜底：data/literature-recent.js
  → 只生成 recent 网络，标记 source_scope = recent_fallback
```

首选 full 本地底座，因为作者联络图需要长期合作网络；recent 只适合近期活跃 overlay。

### 4.2 作者角色识别

| 角色 | 字段来源 | 规则 |
|---|---|---|
| 全作者 | `authors` / `author_affiliations` | 仅用于热力图，不用于合作边 |
| 第一作者 | `first_authors` 或 `author_affiliations.is_first` | 支持共同第一作者；`EqualContrib=Y` 可纳入 first author set |
| 通讯作者 | `corresponding_authors` 或 `author_affiliations.is_corresponding` | 优先 email-derived；若只有 last-author fallback，需在 audit 标记置信度 |
| 末位作者 | `is_last` | 不自动纳入联络图，除非同记录标记为 corresponding fallback |

### 4.3 affiliation → 医院归一化

归一化目标：hospital-level canonical institution。

```text
raw affiliation
  → 清理邮箱/地址/科室前缀
  → 抽取 hospital / medical center / affiliated hospital / institute
  → canonical alias 规则映射
  → hospital_key
  → 省 / 市 / 地区映射
```

#### 医院归一化原则

| 场景 | 规则 |
|---|---|
| `Huashan Hospital, Fudan University` | 节点为 `Huashan Hospital, Fudan University` |
| `Department of Neurology, Huashan Hospital...` | 去科室，保留华山医院 |
| `Fudan University` 与 `Huashan Hospital` 同时出现 | 优先医院，不用大学节点替代医院 |
| `First Affiliated Hospital, Sun Yat-sen University` | 必须结合后文大学名生成完整医院名 |
| 只有大学无医院 | 可作为 `unresolved_academic_institution`，不进入默认 hospital graph；进入 audit |
| 多院区/别名 | 通过 alias table 归并到 canonical key |

### 4.4 中国地区映射

输出字段：`country`、`region`、`province`、`city`、`geo_level`。

建议先复用 `build-frontend-data.py` 中现有 `CHINA_LOCATION_RULES`，再逐步扩展别名表。

## 5. 图数据 schema

建议新增公开产物：`data/china-author-network.js`，全局对象：`window.MG_CHINA_AUTHOR_NETWORK`。

```js
window.MG_CHINA_AUTHOR_NETWORK = {
  generated_at: "2026-..",
  source_scope: "full" | "recent_fallback",
  inclusion_policy: {
    geography: "china_only",
    heatmap_authors: "all_authors",
    graph_authors: "first_and_corresponding_authors",
    edge_threshold: 1,
    institution_level: "hospital_canonical"
  },
  summary: {
    papers: 0,
    papers_with_graph_authors: 0,
    hospitals: 0,
    edges: 0,
    unresolved_affiliations: 0
  },
  nodes: [],
  edges: [],
  papers: {},
  heatmap: [],
  aliases: {},
  audit: {}
};
```

### 5.1 nodes

| 字段 | 说明 |
|---|---|
| `id` | hospital canonical key |
| `label` | canonical hospital name |
| `label_zh` | 可选中文名 |
| `province` / `city` | 地区 |
| `paper_count` | 关联文献数 |
| `first_author_paper_count` | 作为第一作者机构出现次数 |
| `corresponding_author_paper_count` | 作为通讯作者机构出现次数 |
| `collaborator_count` | 合作医院数量 |
| `degree` | graph degree |
| `top_authors` | 该院第一/通讯作者 Top N |
| `top_topics` | 主题/药物/证据方向 |
| `recent_active` | 近一年是否活跃 |
| `paper_ids` | PMID list，前端可懒加载详情 |

### 5.2 edges

| 字段 | 说明 |
|---|---|
| `id` | `${source}__${target}` |
| `source` / `target` | hospital node id |
| `weight` | 合作文献数，阈值 ≥1 |
| `paper_ids` | 合作文献 PMID list |
| `first_author_hospitals` | 哪些文献由哪方第一作者牵头 |
| `corresponding_author_hospitals` | 哪些文献由哪方通讯作者牵头 |
| `top_authors` | 合作边涉及的第一/通讯作者 |
| `top_topics` | 合作主题 |
| `latest_date` | 最新合作文献日期 |

### 5.3 papers

`papers` 用 PMID 作 key，避免 nodes/edges 重复塞完整文献信息。

| 字段 | 说明 |
|---|---|
| `pmid` | PubMed ID |
| `title` | 标题 |
| `journal` | 期刊 |
| `pub_date` / `entry_date` | 日期 |
| `evidence_level` | 证据等级 |
| `study_types` | 研究类型 |
| `china_related` | 中国相关 |
| `authors_graph` | 本文纳入 graph 的第一/通讯作者及机构 |
| `all_author_hospitals` | 热力图用全作者医院 |

### 5.4 heatmap

| 字段 | 说明 |
|---|---|
| `province` / `city` | 地区 |
| `hospital_count` | 医院数 |
| `paper_count` | 文献数 |
| `all_author_occurrences` | 全作者 affiliation 出现次数 |
| `top_hospitals` | 医院 Top N |

### 5.5 audit

| 字段 | 说明 |
|---|---|
| `unresolved_affiliations` | 无法医院归一化的 raw affiliation Top N |
| `ambiguous_hospitals` | 多候选医院 |
| `corresponding_fallback_count` | 末位作者 fallback 次数 |
| `non_hospital_institutions_excluded` | 被排除的大学/研究所 |
| `sample_checks` | 抽样验证记录 |

## 6. 构建管线设计

建议新增脚本：`scripts/buildChinaAuthorNetwork.py`。

```text
run-weekly-pipeline.py
  → build-frontend-data.py
  → buildFullLiteratureIndex.py
  → buildCommunityData.py
  → build-knowledge-data.py
  → buildChinaAuthorNetwork.py   # 建议插入这里
  → build-curated-topic-data.py
  → buildWikiTopicCoverage.py
  → buildLandscapeInsights.py
  → generate-weekly-summary.py
  → generate-pipeline-status.py
```

插入理由：
1. 需要 full/recent 文献与作者字段。
2. 可复用专家画像/机构归一化后的规则。
3. 生成结果供 `knowledge.html` 和 `data-ops.html` 消费。

### 6.1 构建步骤

1. 读取 full 或 recent 输入。
2. 过滤中国相关文献。
3. 对每篇文献解析：全作者医院（heatmap）与第一/通讯作者医院（graph）。
4. 归一化医院 alias，生成 canonical key。
5. 生成 node 累计统计。
6. 对每篇文献内的 graph hospitals 做两两组合，生成 edge，阈值 ≥1。
7. 生成 papers 字典。
8. 生成 heatmap 地区聚合。
9. 生成 alias/audit。
10. 写出 `data/china-author-network.js`。

## 7. 前端交互设计

### 7.1 推荐页面结构

在 `pages/knowledge.html` 新增 tab：`中国作者联络图`。

```text
知识库
  ├── 知识图谱
  ├── 社区视图
  ├── 证据矩阵
  ├── 中国作者联络图   # 新增
  └── 跨库检索
```

### 7.2 首屏布局

| 区域 | 内容 |
|---|---|
| 左侧筛选 | 省份、城市、医院、主题、证据等级、年份、仅近一年活跃 |
| 中央图谱 | hospital nodes + hospital-hospital edges，SVG 或 Canvas |
| 右侧详情 | 节点/边详情、合作文献、作者列表、PubMed 链接 |
| 顶部 stats | 文献数、医院数、合作边数、未归一化率、更新时间 |
| 下方/切换 | 中国热力图：按全作者统计省市/医院活跃度 |

### 7.3 节点点击

点击 `Huashan Hospital, Fudan University` 后显示：

1. 基本信息：省市、文献数、第一作者次数、通讯作者次数。
2. 合作医院列表：按 edge weight 排序。
3. 代表作者：第一/通讯作者 Top N。
4. 主题分布：FcRn / 补体 / RWE / 诊断等。
5. 文献清单：PMID、题名、期刊、年份、证据等级。
6. 操作入口：跳转 MSL 专家画像筛选、PubMed、文献页关键词过滤。

### 7.4 边点击

点击两家医院之间的线条后显示：

1. 合作医院 A ↔ B。
2. 合作文献数与最新合作日期。
3. 合作 PMID 清单。
4. 每篇文献中的第一作者/通讯作者及所属医院。
5. 主题/药物/研究类型聚合。
6. 可复制为 MSL 拜访准备素材。

### 7.5 搜索与筛选

| 筛选 | 行为 |
|---|---|
| 医院搜索 | 高亮匹配节点并聚焦邻域 |
| 省/市 | 只显示该地区节点及其边，可选择保留跨省边 |
| 主题 | 根据 edge/node paper topics 过滤 |
| 年份 | 支持全量 / 近3年 / 近1年 |
| 证据等级 | I–V 多选 |
| 合作强度 | 虽然数据边阈值 ≥1，UI 可选择显示 ≥2 / ≥5 以降低视觉噪声 |

## 8. 性能策略

1. 默认加载 `china-author-network.js` 聚合对象，不加载 full 文献大文件。
2. `papers` 字典只保留必要字段；abstract 不进入首版图谱产物。
3. 如果文件超过 1–2 MB：
   - `chinaAuthorNetworkIndex.js`：summary + nodes + lightweight edges。
   - `chinaAuthorNetworkPapers-*.js`：按省份或 edge shard 懒加载文献清单。
4. 首屏默认展示 Top connected hospitals 或当前筛选后的核心子图；不要一次渲染所有边。
5. 节点/边详情按 PMID list 从本地 `papers` 字典取，避免重复数据。

## 9. 质量门与校正机制

### 9.1 必须输出 audit

| 质量指标 | 建议阈值 |
|---|---:|
| 中国相关文献中可解析作者字段比例 | ≥90% |
| graph author 有医院归一化比例 | ≥80% 首版；后续 ≥90% |
| unresolved affiliation Top 50 人工复核 | 必做 |
| edge paper list 与 PMID 回链准确率抽样 | ≥95% |
| 医院 alias 重复率 | 每轮下降 |

### 9.2 人工校正文件

建议新增：`data/china-hospital-aliases.json`。

```json
{
  "Huashan Hospital, Fudan University": {

    "province": "上海",
    "city": "上海",
    "aliases": ["Huashan Hospital", "National Center for Neurological Disorders"]
  }
}
```

公开站可提交 alias 表；它不含敏感信息。

## 12. 推荐结论

模块2应落在 `知识库` 页面，作为独立“中国作者联络图”tab；数据由 `scripts/buildChinaAuthorNetwork.py` 在每周 pipeline 中生成 `data/china-author-network.js`。首版严格按用户决策：热力图用全作者，联络图只用第一作者和通讯作者，医院层级归一化，合作边阈值 ≥1，点击节点/边均能查询机构连接与合作文献清单。
