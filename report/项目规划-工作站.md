## 一、定位

| v1 情报中心 | v2 学术工作站 |

## 三、7 个页面

| 卡片 | 页面内容 |
|:----|:--------|
| 📄 前沿进展报告 | 筛选器（源/时间/关键词/证据等级）→ 结果预览 → 勾选条目 → 选格式生成 |
| 🏥 治疗格局报告 | 输入领域话题+侧重点 → LLM 提取处理 → 预览 → 微调 → 选格式生成 |
| 🎯 竞品应对策略 | 输入竞品名称 → 自动检索全源 competitor 数据 → 预览 → 选格式生成 |
| 📊 自由探索 | 筛选器 → 卡片列表 → 勾选加入简报篮，可转入正式任务 |
| 📎 素材库 | 浏览证据卡片/竞品对比表/图表模板 → 复制引用 |
| 📌 历史产出 | 最近 10 条 → 类型筛选 → 下载/重新生成/删除 |
| 🔧 数据状态 | 各源更新时间、数据量、手动扫描 poster 目录、触发管线、更新日志 |

## 四、6 个任务卡片定义

| # | 卡片 | 本质 | 输入 | 输出 |
|:-:|:----|:----|:----|:----|
| 1 | 📄 前沿进展报告 | 阶段性总结"最近有什么新东西"，文献+会议综合 | 时间范围、关键词、证据等级 | markdown / HTML / PPT |
| 2 | 🏥 治疗格局报告 | 回答结构性问题（某个领域/靶点的全局图景） | 领域话题、时间、侧重点 | 结构化全景报告 |
| 3 | 🎯 竞品应对策略 | 单点攻击方案（针对某个竞品的情报分析） | 竞品名称 | 竞品分析报告 |
| 4 | 📊 自由探索 | 中间态入口——翻卡片→勾选→简报篮→转入正式任务 | 任意筛选组合 | 简报篮（非最终产出） |
| 5 | 📎 素材库 | 展示型——证据卡片、竞品对比表、图表模板，复制引用 | 选模板 | 引用内容（非产出任务） |
| 6 | 📌 历史产出 | 最近 10 条产出，类型筛选，可下载/重新生成/删除 | 选历史产出 | 复用或重新生成 |

**产出形式不绑定任务：** 每个任务在生成时选择输出格式（markdown / HTML / .pptx / .xlsx）。

## 五、数据层

所有源扁平化，统一 schema：

| 数据源 | 文件 | 标记 |
|:-----|:----|:----|
| PubMed 全量文献 | `data/literature-full.js`（.js+gzip 压缩） | `source: pubmed` |
| 会议摘要 | `data/conferences.js` | `source: aan/ean/aanem` |
| 手动 poster | `data/uploads/*.pdf` + `poster-manifest.json` | `source: poster` |
| 临床试验 | `data/trials.js` | `source: ctgov/chictr` |
| 监管动态 | `data/regulatory.js` | `source: fda/nmpa` |
| 素材库 | `data/materials/*.json` | `source: material` |

统一条目携带 `tags: ["competitor", "fcRn", "china"]`，竞争情报通过 tag 筛选实现。

全量文献约 10MB，.js+gzip → 浏览器加载约 3-4MB，近一年是筛选默认值。

手动 poster：丢至 `data/uploads/`，运行 `scripts/scan-uploads.py` 生成 manifest。
