# 中国省级地图来源与单层交互说明

## 标准地图参考

- 来源：自然资源部标准地图服务系统
- 浏览页：<http://bzdt.ch.mnr.gov.cn/browse.html?picId=%224o28b0625501ad13015501ad2bfc0135%22>
- 地图名称：中国地图（分省设色）1∶1600万（横版、无邻国、线划（一））
- 审图号：`GS（2016）2923号`
- 图中署名：自然资源部 监制
- 可编辑格式：官方下载入口提供 EPS 格式，页面显示时不再使用 JPG 底图与透明 SVG 叠层。

## 网站交互地图

- 浏览器端使用 `china-provinces.svg` 作为单层可编辑省级 SVG：省份 path 本身承担边界显示、热力着色和点击 hit-area。
- 前端在地图说明中标注 `单层可编辑省级 SVG · 审图号 GS（2016）2923号`，避免“官方 JPG + 透明数据层”错位。
- 热力颜色代表医院 affiliation 相关去重 PMID 数；它是医学情报数据层，不改变地图行政边界含义。

## 合规备注

自然资源部标准地图服务说明，直接使用标准地图时应标注审图号；对地图内容进行编辑、裁切或叠加专题内容后公开，应遵守《地图管理条例》等规定并按要求履行地图审核。本站为交互式医学情报工作台展示；正式论文、宣传材料或其他对外正式地图用途，仍应由发布方按“谁公开、谁送审”原则进行合规确认。
