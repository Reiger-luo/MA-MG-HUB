# 中国省级底图来源与许可

- 文件：`china-provinces.svg`
- 来源：[`@svg-maps/china`](https://www.npmjs.com/package/@svg-maps/china) 2.0.0
- 上游：MapSVG 的 China SVG map
- 许可：Creative Commons Attribution 4.0 International（CC BY 4.0）
- 用途：仅用于站内省级文献/医院分布示意，不作为行政边界、导航或测绘底图。

## 使用说明

站点前端显示来源说明，并保留本文件作为仓库内 attribution 记录。中国大陆、香港、澳门和台湾继续按数据层独立筛选；该 SVG 主要用于默认大陆省级视图，台湾筛选使用独立排行/统计视图。

## 官方地图合规备注

自然资源部标准地图服务和国家基础地理信息中心提供更权威的标准地图与基础地理数据，但公开使用地图需要保留审图号；对标准地图进行编辑、裁切或叠加后公开，可能触发地图审核要求。因此当前交互图使用 CC BY 4.0 的简化省级示意底图，不宣称为官方标准地图。若用于论文、宣传材料或正式对外发布地图，应改用自然资源部标准地图服务的合规版本并按要求标注审图号/履行审核。
