等级分类说明
ISystematic Review / Meta-Analysis随机试验系统综述 / 荟萃分析 / 间接治疗比较；或预后 inception cohort 系统综述
IIRandomized Controlled Trial本研究存在随机分组或随机分配的临床对照试验
Prognostic Inception Cohort预后问题中的 inception cohort
IIINon-randomized Controlled Cohort前瞻性对照队列 / 非随机对照临床研究
Adjusted Retrospective Cohort回顾性对照 + 统计校正（PSM/IPTW 等）
Post-marketing Controlled Follow-up上市后安全性随访 / 监测研究；需有队列或随访设计且样本量足够
Prognostic Cohort预后 / 风险因素 / 进展结局队列研究
Biomarker Prognostic / Prediction External Validation生物标志物-结局关联研究 / 明确外部验证预测模型
Diagnostic Accuracy Study诊断/监测准确性研究（无法确认连续入组与盲法时按保守等级）
IVHistorical Control / Case-Control回顾性对照（未校正）/ 病例对照
Cross-Sectional / Survey / DCE横断面、问卷、患者偏好或离散选择实验
Single Arm单臂研究（含无真实外部对照的真实世界 / 回顾性研究）
Poor-quality Prognostic Cohort回顾性、质量受限或无法确认入组质量的预后队列
Prediction Model Development预测模型开发 / 内部验证模型
Diagnostic Case-Control / Scale Validation诊断病例对照 / 量表或监测工具验证
Pharmacovigilance普通药物警戒 / FAERS / disproportionality，未满足 Level III 上市后随访条件
Case Report / Case Series病例报告 / 病例系列；按 CEBM 2011 case-series 低等级临床证据桶处理
Genetic / Omics AssociationGWAS、omics、遗传关联等探索性观察关联，不自动等同机制推理
Biomarker Association未明确结局预测或外部验证的探索性 biomarker association
Systematic Review of Case Reports病例报告或病例系列的系统综述
Systematic Review of Uncontrolled Studies无对照单臂研究、病例系列或比例 meta-analysis 的系统综述
VMechanism-based Reasoning机制推理；不能直接外推为疗效或安全性结论
