等级分类说明
ISystematic Review / Meta-Analysis / ITC / Prevalence Survey (Random Sample)随机试验系统综述 / 荟萃分析 / 间接治疗比较；预后 inception cohort 系统综述；患病率域本地当前随机抽样调查 / 普查

Prognostic Inception Cohort预后域官方 L2：在疾病早期统一时点入组并随访的队列（inception cohort）
Diagnostic Accuracy Study (Blinded)诊断域官方 L2：一致参考标准 + 盲法 + 前瞻/连续入组的横断面准确性研究（如 SCREAM）。注意此类不是 RCT，但按诊断域为 L2
IIINon-randomized Controlled Cohort治疗/伤害域：非随机对照队列 / 随访研究
Adjusted Retrospective Cohort回顾性对照 + 统计校正（PSM/IPTW 等）
Post-marketing Controlled Follow-up常见伤害域官方 L3：足量上市后安全性监测，需队列/随访设计且样本量足够
Prognostic Cohort预后域官方 L3：普通队列 / RCT 对照臂
Diagnostic Accuracy Study诊断域：无法从摘要确认连续入组与盲法时按保守 L3；符合参考标准+盲法者升 L2
Prevalence Survey患病率域官方 L3：本地非随机抽样调查；随机抽样普查为 L1
IVHistorical Control / Case-Control治疗/伤害/诊断域 L4：历史对照 / 病例对照
Single Arm单臂研究（无真实外部对照的真实世界 / 回顾性研究），按病例系列 L4 处理
Poor-quality Prognostic Cohort预后域官方 L4：回顾性、质量受限或无法确认入组质量的预后队列
Diagnostic Case-Control诊断域官方 L4：参考标准不一致或非独立的病例对照
Case Report / Case Series病例报告 / 病例系列；按官方 case-series L4 处理
Systematic Review of Case Reports病例报告或病例系列的系统综述；证据基础仍为病例级 L4
